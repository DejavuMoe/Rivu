# 界面重新设计方案：「昼夜之水」

状态：**待确认**（2026-11-20）。只在原型 `designs/rivu-svelte` 的分支 `design/redesign-flow` 上，`apps/dashboard` 没有动。确认之前 [`apps/dashboard/DESIGN.md`](../../apps/dashboard/DESIGN.md) 仍是现行规范；确认之后把这份方案里「规则的变化」并进去，再在看板里实现。

## 想解决什么

原来的界面干净、一致，但太素：全是灰色，没有一处让人记得住。这次要让第一眼就有印象，同时不丢掉「几秒钟看懂访问情况」这件正事。

## 一句话

Rivu 的名字来自拉丁语的「溪流」。把访问量当成一条水流，把访客放在一颗活的地球上。

## 四条原则

1. **冷色记录过去，暖色表示现在。** 已经发生的数据（趋势线、条形、地球上有访客的国家）用靛蓝到青色这一段「水流色」，越靠近现在越亮。此刻在线的人用暖色的「灯光色」，像夜里地球上的灯火。绿和红只表示涨跌。
2. **界面本身是单色的。** 按钮、文字、边框都是墨色（主按钮从蓝色改成墨色，和标志一致），颜色全部留给数据。
3. **只有一处张扬：地球。** 其余部分保持安静和克制。
4. **动效只在到达的那一刻。** 第一次打开时曲线从左画到右、条形依次长出、数字从 0 数到位，之后静止。一直在动的只有地球和「在线」的光点。系统设置了「减少动效」时全部不动。

## 具体改了什么

| 位置 | 原来 | 现在 |
|---|---|---|
| 看板最上面 | 指标条 + 趋势图 | 指标条 + 趋势图（这段时间）+ 右边一扇「此刻」的窗：夜空里的地球、在线人数、在线最多的三个国家 |
| 地图 | 平面世界地图 | 3D 点阵地球：可以拖着转（带惯性），空闲时慢慢自转，按此刻太阳的位置分昼夜 |
| 「地区」卡片 | 「地图」标签页是平面地图 | 同一个标签页换成地球，有访客的国家按多少分五档 |
| 登录等独立页 | 浅色页面上一张卡片 | 夜空，地球从底边升起，上面浮着标志和卡片 |
| 趋势线 | 蓝色实线 + 平涂 | 颜色沿时间由深到亮，下方向下淡出；进行中的那个时间点是灯光色并带一圈光 |
| 条形 | 灰色 | 水流色，由深到浅 |
| 指标数字 | 24px 正文字体 | 28px 展示字体（Bricolage Grotesque），中文单位「万」「分」「秒」排小一号；变化量是数字下面的小色块 |
| 页面底色 | 页面和卡片同色，靠细线分开 | 页面是淡冷灰的「水面」，卡片是白色的「纸」；侧栏和页面同在水面上，没有分隔线，选中的行是一张白纸 |
| 圆角 | 6 / 8 / 12 | 8 / 14 / 18，越大的容器越圆 |

地球是自己画的（一张 canvas，`src/lib/charts/globe.ts`），没有引入第三方库，画法参考了 romi 的地球。陆地的点由平面地图已有的国家形状在浏览器里算出来，没有新增地图数据。地球和国家形状仍然按需加载，不进首屏。

## 规则的变化（确认后写进 `DESIGN.md`）

| 现行规则 | 改成 |
|---|---|
| 只有四个字号（12 / 14 / 16 / 24） | 六个：12 / 14 / 16，页面标题 20，指标数值 28，一页里最大的数 44（此刻在线） |
| 一种字体 | 两种：正文仍是 IBM Plex Sans；数字和标题用 Bricolage Grotesque（SIL OFL 许可，随应用打包，41 KB，只含拉丁字符） |
| 不用渐变、不用发光 | 渐变只用在数据上（趋势线、条形、地球），并且只能写在令牌里，组件里仍然不许写；深色模式的趋势线带一点光 |
| 阴影只给浮层 | 浅色模式的卡片有一层几乎看不见的影子，同样只能用令牌 |
| 不加装饰性动画 | 允许「到达」的动画和「此刻」的光点，时长都用令牌；其余不变 |
| 强调色是蓝色，主按钮是蓝色 | 强调色是靛蓝（链接、焦点、开关）；主按钮是墨色 |
| 在线状态是绿色的点 | 灯光色（浅色主题橙色，深色主题琥珀色），带慢慢扩散的光 |

不变的：颜色仍然以 Radix Colors 为基础、组件只用语义令牌、线宽 0.5px、不写中点分隔符、不要眉题、文案规则、无障碍要求、每个状态都要有交代。

检查脚本 `tools/design-lint/check.mjs` 已经按新令牌放宽（多两个字号令牌、两个阴影令牌），其余规则照旧。

## 怎么看

原型服务器：<http://localhost:5173/>（启动方法见 [`designs/rivu-svelte/README.md`](../../designs/rivu-svelte/README.md)）。

- 看板：`#/s/1`。右下角「评审」面板切换主题、语言、角色、数据状态。
- 地球：看板右上的「此刻」，以及「地区」卡片的「地图」标签页。可以拖；鼠标指到国家看数字；聚焦后用左右方向键逐个国家看。
- 登录页：`#/login`。
- 站点列表：`#/sites`；合并看板：`#/sites/combined`。
- 手机宽度：把窗口缩到 400px 以下。

## 还没做的

- **只改了原型。** 原型和看板共用的令牌、组件（`lib/ui`、`lib/charts`）现在两边不一致，检查脚本的「两边逐字节相同」这一项在这个分支上不通过。确认后和看板实现一起补齐。
- **各页面没有逐页重排。** 看板、站点列表、登录页是重新设计的；设置、成员、账号、接入诊断等页面只是跟着令牌和组件换了外观，没有单独调整版式。
- **平面地图组件还留着**（`WorldMap.svelte`），现在没有地方用，确认后删掉。
- **没有测量。** 地球在低端手机上的帧率、字体和地球对看板体积的影响都还没量；实现到看板时按 [`../product/constraints.md`](../product/constraints.md) 的要求量过再合并。
- **没有用真实读屏软件和真实手机试过。**

## 要你定的

1. 整体方向行不行：「此刻」的夜空窗口放在看板最上面，可以吗？它让趋势图窄了约三分之一。
2. 在线状态从绿色改成暖色，接受吗？绿色现在只表示「上涨」和「成功」。
3. 主按钮从蓝色改成墨色，接受吗？
4. 看板的「此刻」需要多查一次「实时、按国家」的数据。实现时会量它的开销；如果你不想加这次查询，窗口里可以只放在线人数和地球，不放光点。
